# Official CAP skills in this course

## Lesson 0 setup

Use the current official repository, https://github.com/capire/skills.git. Skills guide implementation practice; AGENTS.md, the chosen runtime, current lesson, one-step teaching and approval rules still define this course. Skills do not authorize future lessons, a runtime conversion or business mutations. The Explore starter is copied using SHORT-STARTER.md, never regenerated by a skill.

Identify the actual coding agent, including inside VS Code. From the course root use the helper with `claude`, `codex`, `cursor` or `vscode` (the latter means GitHub Copilot, not every VS Code extension):

```sh
node course/scripts/cap-skills.mjs codex --plan
node course/scripts/cap-skills.mjs codex --install
node course/scripts/cap-skills.mjs codex --verify
```

Replace `codex` with the selected agent. Plan is read-only and prints a command proposal; it does not inspect installation state. Run --verify and inspect the installed files/source to assess existing matching project installations, and reuse a suitable current set without downloading again. Do not blindly overwrite conflicting files or install duplicates globally. The official manual route is `npx skills add https://github.com/capire/skills.git --skill cap-developer cap-add-remote-service cap-trivia cap-upgrade --agent codex --copy`; substitute `claude-code`, `cursor` or `github-copilot` as appropriate, select the current official skill set, and keep project scope (no `-g`). Inspect the current CLI options before using the manual route. `npx` may download its CLI into the npm cache.

An existing official native plugin installation (for example Claude Code or Copilot) can be reused when the active agent confirms its official source and reads the current cap-developer SKILL.md and actual task references. The helper verifies only the project CLI layout, not native plugin registration or access; a missing project result alone is not a reason to install a duplicate. Record `installationRoute: project-cli|native-plugin` and native skill availability separately from helper results. The default project install includes all four skills below. When reusing a native plugin, cap-developer is required for the current CAP implementation task; absent remote-service, trivia or upgrade skills may remain absent and unused until an explicitly requested task needs them. Confirm the applicable official skill then, rather than treating an unrelated optional skill as a setup blocker.

Install the current official set: `cap-developer`, `cap-add-remote-service`, `cap-trivia` and `cap-upgrade`. Installation is not activation. The active coding agent must read the installed `cap-developer/SKILL.md` and the current task's referenced guidance before implementation. Record activation as pending until that read is confirmed; a helper's file verification cannot prove the agent loaded instructions. Read the live installed upstream references rather than copying recipes into this course.
