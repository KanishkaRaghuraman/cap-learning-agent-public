# Choose your learning journey

**1 — Build a CAP app:** learn CAP while building Incident Management step by step. After a brief CAP introduction, choose Java or Node.js. Lessons0–12 cover setup, the app, MCP and the final agent topic. Both runtimes finish with a hands-on native application MCP exercise; no additional API key is required. Optional Node.js Fiori embedding follows only with a supported key and explicit choice.

**2 — Explore MCP and agents:** start from the prepared Node.js app. Lesson0 checks tools and installs dependencies; you start the app in your terminal and confirm its preview. Lessons1–3 cover connecting/querying, a business action, and the app-hosted agent topic.

Selecting option2 starts routine setup directly. The agent provides terminal instructions, checks HTTP readiness after you start the server and asks you to open the preview. No browser automation or repeat application generation is required. Keep the terminal open. Restarting the in-memory sample resets local data changes.

For learning activities, a short explanation precedes an adaptable example request. You can use your own words, ask questions and experiment. There is one course chat; no Teacher/Builder copying. Native permissions and confirmation before a business-data change remain.

Resume preserves your app, runtime and progress. See [starter setup](SHORT-STARTER.md).
