# Vibe with CAP

Learn the **SAP Cloud Application Programming Model (CAP)** by building an Incident Management application with your coding agent.

The Learning Agent explains the concepts, guides you through the changes, and helps you try them in a running app. Ask questions, adapt the example prompts, and learn how CAP applications work with MCP and AI agents.

## Get started

### 1. Download the course

Select **Code → Download ZIP** on GitHub and extract it, or clone the repository:

```sh
git clone https://github.com/KanishkaRaghuraman/cap-learning-agent-public.git
```

### 2. Open it in your editor

Open the **entire course folder** in your preferred code editor, such as VS Code or Cursor.

Open a coding agent, such as Claude Code or Codex, and sign in. Your agent needs access to the project files, terminal and MCP tools.

### 3. Start to vibe with CAP

In your agent's chat, type:

```text
Read AGENTS.md and start the CAP learning journey.
```

The agent will guide you through the required tools and setup, then help you follow your chosen path. For manual configuration, see the [setup guide](course/docs/AGENT-SETUP.md).

## Choose your path

- **Build from scratch:** learn CAP while building the app step by step, using Node.js or Java.
- **Explore MCP and agents:** start with a prepared Node.js app, connect an assistant, ask about incidents and try a business action with approval. You can also choose to add chat inside the Fiori app.

Use the example prompts as starting points or ask in your own words. The agent explains what changes and helps when you get stuck.

## Continue later

Open the same folder and tell your agent:

```text
Read AGENTS.md and resume my existing course.
```
